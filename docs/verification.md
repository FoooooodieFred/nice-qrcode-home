# 验收记录

日期：2026-09-19。环境：Windows / Node.js 24.21.0 / npm 11.19.0 / Codex 内置 Chromium 浏览器。

## 自动检查

- npm run build：通过 TypeScript 检查和 Vite 生产构建，产物位于 dist/。
- npm test：3 个文件、28 个测试全部通过。
- npm audit：依赖安装完成后报告 0 个漏洞。已将旧 Vitest 升级至 4.1.11，修复审计发现的 mocker 开发依赖漏洞。
- npm run format:check：Prettier 代码格式检查。

测试涵盖：

1. 可执行/非许可协议无法变成可点击链接，合法网页和平台协议可正常使用。
2. 相似域名不会被误认成支付平台，普通文本和无协议域名正确处理。
3. 解码器错误回退、首个成功结果短路、自定义引擎注册。
4. IndexedDB 持久化卡片、设置和二进制图片。
5. 删除分组保留收藏，共享图片仅在最后一个引用删除后清理。
6. 无效批次不发生部分写入；有效批次卡片与资产一起写入。
7. 恢复中途校验失败回滚，不覆盖原数据。
8. 非法 JSON、版本、重复 ID、悬空引用、不允许的图片类型、越界设置被拒绝。
9. 完整备份往返保留原图字节、图片引用和扩展设置。

- 外观可在深色与浅色间切换。
- 无效备份被设置面板拒绝，现有收藏保持。

## 尚需设备/浏览器验收

- 真实摄像头授权、连续识别与摄像头硬件释放没有用物理摄像头实测。
- 剪贴板图片写入、系统分享面板、PNG/SVG/分享卡/备份文件的最终保存取决于浏览器权限和宿主行为，需在目标浏览器确认。
- 直连网站元数据受对方 CORS 策略影响，默认关闭。
- 未执行公共托管发布、跨浏览器矩阵、PWA 或云同步测试；后两项不在 v1 实现范围。
